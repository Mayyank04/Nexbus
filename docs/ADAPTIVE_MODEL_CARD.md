## 1. Model Overview

The NEXBUS Adaptive Forecasting Engine combines spatio-temporal graph diffusion with rolling-origin baseline evaluation. Under nominal operational conditions, the ST-GNN parametric surrogate delivers sub-15ms multi-horizon passenger load forecasts. If upstream data drift or missing sensor anomalies are detected, the system dynamically falls back to an Autoregressive Ridge model (`v1.3.1-arridge`) or Exponentially Weighted Moving Average (`v1.2.0-ewma`).

- **Primary Application:** Bounded decision support for transit depot managers, corridor scheduling supervisors, and commuter journey advisory interfaces.

## 3. Mathematical Architecture

### 3.1 Spatial Diffusion Adjacency
Graph edges between stop nodes $i$ and $j$ follow Gaussian distance decay with highway connectivity scaling:
$$W_{ij} = \exp\left(-\frac{d(i, j)^2}{\sigma^2}\right) \cdot \mathbb{I}_{\text{connected}}(i, j)$$
Where $d(i, j)$ represents network distance in meters along the GTFS road centerline, and $\sigma = 4,500\text{ m}$.

### 3.2 Temporal Fourier Kernel
Captures diurnal and weekly rush-hour cycles without requiring persistent recurrent state tensors:
$$T(t) = \sum_{k=1}^4 \left(a_k \cos\left(\frac{2\pi k t}{24}\right) + b_k \sin\left(\frac{2\pi k t}{24}\right)\right) \cdot (1 - 0.22 \cdot \mathbb{I}_{\text{weekend}})$$

### 3.3 Bayesian Uncertainty Estimation
Credible bounds reflect both epistemic parameter uncertainty and aleatoric congestion shock variance:
$$L_{95}(t+h) = \hat{Y}(t+h) - z_{0.975} \cdot \sigma_{\text{residual}}(h)$$
$$U_{95}(t+h) = \hat{Y}(t+h) + z_{0.975} \cdot \sigma_{\text{residual}}(h)$$
Where $\sigma_{\text{residual}}(h) = \sigma_0 \cdot \sqrt{1 + 0.35 \cdot \frac{h}{15}}$.

## 4. Drift Monitoring & Automated Remediation

| Drift Dimension | Detection Method | Trigger Threshold | Remediation Action |
|---|---|---|---|
| **Residual Drift** | Rolling mean error $\overline{e}_{100}$ | $|\overline{e}| > 2.5\text{ percentage points}$ | Flag `MODERATE_DRIFT`, widen confidence intervals. |
| **Velocity Shift** | Speed ratio $V_{\text{obs}} / V_{\text{free}}$ | $CI > 70\%$ | Trigger Congestion Dampener, alert depot supervisors. |
| **Missing Features** | Ingestion ledger heartbeat | $\Delta t > 180\text{ s}$ | Fall back to `v1.2.0-ewma` or historical diurnal profile. |

## 5. Epistemological Transparency

Every prediction generated by the engine outputs an immutable payload containing:
- Exact Model Version (`v1.4.2-stgnn`)
- Input Feature Timestamp
- Prediction Generation Timestamp
- Horizon Minutes (15, 30, 45, or 60)
- Bayesian Credible Intervals (80% and 95%)
- Epistemological Status: `MODEL PREDICTION`
